# Korean Design MD

국내 주요 서비스의 디자인 레퍼런스를 한눈에 볼 수 있는 인덱스 페이지입니다.

## 소개

토스, 카카오톡, 네이버, 쿠팡, 배달의민족 등 **73개 국내 서비스**의 UX/UI 디자인 스펙을 카테고리별로 정리했습니다. 서비스 기획자, 디자이너, 개발자가 국내 앱/웹의 디자인 패턴을 빠르게 참고할 수 있도록 만든 레퍼런스 모음입니다.

|----------|-----------|

## 사용 방법

`Korean Design MD_index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.  
별도 서버나 설치 없이 로컬에서 실행됩니다.

## 만든 이

메가존 AXO-TF — 기획/UX 관점에서 국내 서비스 디자인을 분석하고 정리한 프로젝트입니다.
